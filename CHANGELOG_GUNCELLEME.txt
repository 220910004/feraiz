Feraiz proje güncelleme özeti
=============================

Bu sürümde yapılan ana mimari değişiklikler:
- Hesaplama için yeni core katmanı eklendi:
  - src/core/engine
  - src/core/schools
  - src/core/rules
  - src/core/specialCases
  - src/core/scenarios
  - src/core/explain
  - src/core/references
- Eski monolit hesaplayıcı korunarak yeni çekirdeğe legacy adapter ile bağlandı.
- App artık doğrudan core/engine/calculateCase üzerinden sonuç üretiyor.
- ResultsDisplay doğrudan hesaplayıcıyı çağırmak yerine yeni adapter/engine katmanını kullanıyor.
- UI için ortak sonuç bölümleri uiResultAdapter içinde toplandı.
- Mezhep politikaları ayrı dosyalara ayrıldı.
- Zevi’l-erhâm, beytülmâl, hacb, asabe, avl, redd ve özel meseleler için ayrı kural modülleri eklendi.
- Haml, hünsâ, mefkud ve münâsehat için senaryo grafiği altyapısı eklendi.
- İzlenebilirlik için trace, reference matrix, engine scope ve school policy verileri sonuç nesnesine bağlandı.
- Otomatik motor testi eklendi ve 24 kritik senaryo geçti.

Komutlar:
- npm install
- npm run test:engine
- npm run build

- Çok nadir zevi’l-erhâm dalları eklendi (kızın alt soyunun ikinci halkası, kız kardeş kız/oğul alt soyu, dayı/hala/teyze çocukları).
- Haml 3 çocuk ihtimaline kadar genişletildi.
- Haml + hünsâ + mefkud birleşik senaryoları tek matriste hesaplanıyor.
- Her birleşik senaryoda münâsehat için ayrı ikinci dağıtım dalı üretilebiliyor.
